# 自动点击器 AutoClicker（安卓）

一款基于「无障碍服务（AccessibilityService）」的安卓自动点击工具，用于自动化重复 UI 操作。

## 核心功能

1. **文字匹配点击**：当屏幕出现你设定的文字（如「是否真人在看」），自动点击。
   - 点击「该文字节点」本身，或
   - 点击你录制的**固定坐标**（适合按钮文字读不到、但位置固定的情况）。
2. **定时点击模式**：无论有没有弹窗，每隔 N 毫秒自动点击一次指定坐标，专治「读不到文字的平台」。
3. **悬浮窗控制**：运行中显示精简控制面板（保存坐标/定时开关/暂停/停止）+ 可拖动坐标标记 + 靠边隐藏。点「⚙ 设置」跳转主界面配置详细参数。
4. **场景管理**：在主界面设置页中管理多个文字匹配场景，独立启停、增删。

## 快速使用

1. 安装并打开 App -> 点「去开启无障碍服务」-> 在系统无障碍里找到「自动点击器 AutoClicker」并开启。
2. 打开你要挂机的视频平台。
3. 用悬浮窗的**绿色圆点**拖动到弹窗的「确定 / 我是真人」按钮上，点悬浮窗「保存坐标」。
4. 点悬浮窗「⚙ 设置」进入设置页：
   - 若弹窗有可读文字：在「文字匹配场景」区点「+」新增，填匹配文字，选点击方式。
   - 若读不到文字：在「定时点击模式」填坐标与间隔（点「用悬浮窗坐标」自动填入），打开开关。
   - 设置完按返回键回到之前的 App。
5. 后台挂着即可，需要时点悬浮窗「暂停 / 停止」。

## 构建方式

### 方式 A：云端构建（推荐，无需装环境）
- 把本工程推到你的 GitHub 仓库。
- 用你的云端构建（GitHub Actions / CODING 等，从 GitHub 拉取本工程）运行构建。
- **构建环境请选择 Gradle 8.6 + JDK 17**（AGP 8.4 需要 Gradle ≥ 8.6）。
- 跑完后在产物（Artifacts）下载 APK。

### 方式 B：Android Studio（本地出 APK）
- 用 Android Studio 打开本工程根目录。
- 菜单 Build -> Build Bundle(s) / APK(s) -> Build APK(s)。
- 产物：app/build/outputs/apk/debug/app-debug.apk，传手机安装（需允许「未知来源」）。

> 本工程最低支持 Android 9（API 28），因为悬浮窗使用 TYPE_ACCESSIBILITY_OVERLAY。
> 工程内已包含 `gradle.properties`（开启 AndroidX），无需额外配置。
